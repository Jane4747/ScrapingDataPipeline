# 从配套表读取图表数值

`extract_table_rows.py` 用 pypdf 读取指定 PDF 页里的中文编号表，输出一个可放入 `pdf-percent-charts.v1` 的 `figures[]` 草稿。适用的表题形如“表 1.2.3 示例标题”，每行依次为类别、第一组的数量和比例、第二组的数量和比例。支持一个或多个系列。

以两组、四个类别、跨两页的示例为例，先从表头确认两组的名称和样本量，按**表格列从左至右**填写 `--series`，从原图数出类别数并填写 `--rows`。在安装了 pypdf 的 Python 环境中运行以下命令（请将示例文件、页码和分组换成自己的资料）。

```powershell
python scripts/pdf_chart_to_pptx/extract_table_rows.py report.pdf --pages 7 8 --id 1.2.3 --series "甲组=100" --series "乙组=50" --rows 4 --out figure.draft.json
```

- `--pages` 使用 PDF 阅读器从 1 起算的连续页码。脚本在目标表题处开始，在下一张图或另一张表的表题处结束，读取续页的同行数据。印刷页码另外记录。
- 同一文本行需要包含完整类别和全部“数量 比例%”列。数量可带千位逗号，比例按保留两位百分数的口径核验。原文的 `0.00%` 可正常读取。有缺项、文本跨行、表头或分母含义不清时，请逐行回看原图。
- 输出的 `categories` 保留类别顺序，`series[].counts` 为原表数量，`series[].values` 为比例小数，`series[].n` 为各系列的分母。表头有 `[N=…]` 时，脚本核对分母及顺序，并按数量除以该组 N 核算每个原文百分数。多个业务项目可同时被选中，各项比例可重叠。
- 读取成功后，对照原图逐项确认图例、类别和数值。将草稿对象放入最终配置的 `figures` 列表，补齐工作表名称 `name`、图名或分层说明 `subtitle`、印刷页码 `sourcePages` 和统计说明 `note`。在配置顶层 `source` 写明文件、报告名与机构。生成 Excel、PPT 的命令见[工作流说明](README.md)。
- 如果只有图片，直接查看清晰原图，按图例录入可辨认的标签，保留图号和页码。模糊、遮挡或缺失的值先记在核对稿，补足后再生成图表。图像截图和扫描 PDF 里的文字需要人工识读或经人工复核的 OCR。可以用 Poppler 的 `pdftoppm -f 7 -l 7 -singlefile -scale-to 1900 -png report.pdf page-7` 查看第 7 页。来源仅给比例时，在最终配置中省略未提供的 `counts`、`n` 字段。

例如某组的数量为 5、N 为 80、原图标注为 6.25%，对应的 JSON 数值为 `counts: [5]`、`n: 80` 和 `values: [0.0625]`。对多个类别合并统计时，先将数量相加再除以 N，最后统一取舍显示精度。
