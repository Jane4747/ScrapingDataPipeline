# 三平台医疗数字化采购更新

从 2024-01-01 起，按公告发布日期更新央采、全国公资和北京公资。截止日由请求固定，默认创建任务当天。新任务、新范围使用新编号；恢复同一范围使用相同编号和 `-Resume`。旧采集与原文不覆盖。

## 启动

使用 `scripts/start-tender-update.ps1`，提供现有 Python、Dagu、Node 与 Artifact Tool 模块目录。不安装依赖、不调用付费搜索或模型。脚本先做离线范围检查，再验证工作流，启动后台 Dagu 并排队，默认弹出任务进度页。服务监听本机 8098；任务和日志位于 E 盘代码库 `outputs/`。

可选参数：`-Start 2024-01-01 -End 2026-10-29 -TaskId <新编号>`；`-NoBrowser` 仅在明确无需弹出页面时使用。`-Resume` 恢复相同请求，不能偷偷改变来源、日期或预算。原请求和初始代码哈希保持不变；兼容修复在 `code-revisions/` 记录原因及新哈希，每个新执行尝试另存代码版本。运行中的进程按其已加载版本继续。不同业务范围必须使用新的任务目录。

## 来源与边界

- 央采：复用中国政府采购网按“中央国家机关政府采购中心”代理机构过滤的公开检索，按月保留缓存；本任务同时保留采购/资审及结果公告。非结果公告不填写中标事实。
- 全国公资：复用现有浏览器采集器；一年前数据走官网声明的 `/his/information/pubTradingInfo/getTradList`，较新数据走当前入口，跨边界月份拆分。到日期上限或响应字段不符不会当作覆盖完成。
- 北京公资：使用官网 `/elasticsearch/index.jsp` 声明的 `/elasticsearch/search` 公开全文检索，按月、医卫关键词查询，不再依赖仅保存近期约105页的普通列表。取页统一为现有的真实自报爬虫标识，国密证书通过 Windows 系统 TLS 校验；不使用浏览器伪装标识，不关闭证书校验。
- 403/429、验证码、非预期响应和日期未生效会保留原因并停止该来源。一个来源失败，其他来源继续。没有付费API、账号注册或认证绕过。
- 三路进程独立，Dagu 全局队列限制同一组业务一次运行，各路维持至少3.5秒请求间隔。重复启动受运行队列与来源锁限制；不自动删除遗留锁。

## 字段与交付

主表保留时间、项目名称、产品、招标单位、客户标签、中标单位、运营商类型、中标金额（万元）、场景、评审专家、网址、公告类型、省份、项目编号、中标金额原文、信息缺口、标签依据、响应人资格要求（对供应商基本要求）、资格预审资质要求；另有来源平台、资格要求出处和原文文件。

专家与资格内容取原文具体章节，保留网址、行号与文本哈希。原文未记载时留空，不将政策常识写成该项目要求。跨公告仅在项目编号与采购人同时一致、内容版本唯一且采购公告时间不晚于结果时补齐资格要求，保留补充来源；冲突不自动选择。采购公告、候选人公示、更正和合同不冒充最终中标公告；预算不当作中标金额。

每路 `progress.json`/`state.json` 与 Dagu 步骤日志显示进度，阶段性数据保存在该路 `records.json` 或月份目录。全部来源结束后，汇总与表格导出步骤生成 `delivery/三平台医疗数字化采购_2024年至今.xlsx`、JSON、CSV与范围说明。失败来源仍在表格“采集范围”中显示，流程不会将部分覆盖改成全量完成。

同名公告不自动合并成独立项目；原文事实与规则标签分开。供应商资质、专家名单和项目关联仍需必要核验；附件专有格式或扫描件未解析时保留缺口。历史缓存复用只限相同请求，不复用当前月份的旧列表来假装已更新当天数据。

## 本机接入与回归

默认弹出的是正式实例 http://127.0.0.1:8098/ ，原8097实例仅为早期离线演示。正式实例的服务、工作流与数据均在仓库 outputs 下。Windows 后台子进程显式继承 DAGU_HOME，防止排队记录与执行进程落在不同目录。

央采以网页 Pager 声明的总页数作为结束条件，避免把超出末页时返回的重复页视为采集失败。全国历史查询使用官网的一年前独立入口；跨当前/历史边界的月份拆分，超时的大时间窗进一步分割为更小的待处理窗口，保留原失败，不把验证码或访问拒绝改作超时重试。北京历史检索使用官网实际的 title 参数与完整医卫检索词，并校验返回日期是否落在请求窗口。

运行记录：主流程 `medical-tender-medical-2024-20261029`，全国网络恢复流程 `medical-national-recovery-2024`。进度页可同时查看两个运行，来源断点锁防止同源重复写入。若央采遇访问挑战，停止该源并保留缓存和缺口；不影响另外来源。
