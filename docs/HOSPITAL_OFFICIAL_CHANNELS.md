# 医院官网采购渠道核查

医院本级官网采购信息是每家医院的必查渠道，适用于全部举办主体。政府采购平台、集团平台与学校统一采购作为并行补充，不能替代本级官网核查。范围仍为原251家北京一级医院、2024年以来医卫数智化招采。

## 查哪些栏目与公告

按官网导航、院务公开、通知公告、招标采购、院内比选、询价议价、采购意向、中标成交、采购结果、更正和终止查找；同时保留正文、附件、发布日、项目号和原始URL。医院自采公告同样纳入发现范围，不能只查政府平台或只检索“数字化”。公告实际产品范围仍由正文和需求附件判断。

## 每院记录哪些信息

医院名称、官网网址、官网主体确认依据、站点所属层级、采购栏目名称和网址、普通通知或院务公开网址、公告示例及发布日期、是否明确供本医院使用、访问结果、未获取原因、证据文件、核验日期与下一步待查内容。正式招采表仍保留用户指定七列；这些渠道字段在独立台账保存。

## 缺口状态必须分开

| 状态 | 正确含义 |
|---|---|
| 未核查 | 尚未进行该医院官网核验 |
| 官网尚未定位 | 已进行有限查找，未确认独立官网；不能说不存在 |
| 官网已确认，采购栏目未定位 | 不能把就医、招聘或应用新闻栏当采购栏 |
| 栏目已定位，访问失败 | 保留超时、HTTP状态、验证码或解析错误及具体URL |
| 栏目可读，未取得相关公告 | 保留已查看页数和日期范围，不能写成无采购 |
| 正文或附件不完整 | 单列缺技术参数、发布日期、供应商、金额或医院使用关系 |
| 上级单位代发 | 标明总院、学校、集团、研究所或政府，逐公告确认医院归属 |

## 离线台账命令

```powershell
python -B scripts/hospital_official_channels.py --roster outputs/beijing-hospital-channel-supplement-20261027/hospital_roster.json --verified outputs/hospital-official-channels-20261027/manual_verifications.json --output-dir outputs/hospital-official-registry-new
```

输出目录必须不存在。该命令只整理已核验输入并生成后续查询计划，执行查询数和网络请求数均为0。真实联网核验原始返回独立保存，不能把planned_queries计作已执行。医院名单与完整证据仅保存在本地outputs。
