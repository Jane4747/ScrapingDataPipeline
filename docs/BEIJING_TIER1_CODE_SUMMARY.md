## 本轮代码改进

1. 用显式base/supplement/output目录与起止日期替代一次性脚本的批次路径。新输出不得覆盖输入或已有成果；非法证据路径、缺文件、不同内容同名证据均报错。
2. 按公告URL与采购包归并，保留一份公告涉及的多个医院；同一字段出现冲突时停止，不能默默覆盖金额或供应商。
3. 保留人工review_decisions中的候选转正式、候选合并和字段修订。查询必须在原始返回中存在，计划查询不能冒充执行记录。
4. 把原251家逐院日志与本轮渠道补查分开计数；不能将26家补查记为又完成251家全量抓取。
5. 可选工作簿制作为显式输入目录；原生链接补写支持已有链接替换，保持无关链接并保护原文件。
