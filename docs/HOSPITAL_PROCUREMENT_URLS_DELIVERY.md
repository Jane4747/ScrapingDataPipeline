## 未完全获取的原因

| 原因 | 已观察情形 | 对数据的影响与下一步 |
|---|---|---|
| 入口隐藏或迁移 | 网站地图才暴露栏目；阜外旧53栏目与现9通知公告不同；旧链接重定向/404 | 从当前官网导航重新定位，历史栏目保留为备用 |
| 主体名称与采购人不同 | 县医院项目采购人为卫健局；学校、总院或集团代发 | 同时查医院正式名、别名和实际采购人；共用入口另列 |
| 网络访问失败 | 容城县人民医院旧域名DNS失败；第六医学中心官网外链目标超时 | 保留明确错误和官方出处；不能据此断定没有网站或栏目 |
| JavaScript跳转/动态正文 | 河北采购首页或县目录返回短跳转HTML，而具体公告列表可读 | 区分跳转与空页面，跟随实际栏目地址；需要时做站点适配 |
| 索引滞后与旧公告失效 | 搜索命中旧页面，当前栏目已换路径 | 回到实际列表与原文核验，不能仅凭搜索摘要填网址 |
| 公开范围与历史覆盖不足 | 仍有440家未定位主入口；部分信息仅见公众号、上级平台或分散公告 | 逐院继续补证；未穷尽历史分页、附件和登录后信息 |
